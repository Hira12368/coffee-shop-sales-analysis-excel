# coffee-shop-sales-analysis-excel
Coffee Shop Sales Analysis — Excel Dashboard

 Project Overview
This project is an interactive coffee shop sales dashboard created using Microsoft Excel.
The goal of the project is to analyze coffee shop sales data and identify useful trends and patterns in sales performance.

 Tools & Skills Used
Microsoft Excel
Data Cleaning
Excel Formulas
Pivot Tables
Pivot Charts
Slicers
Data Visualization
Dashboard Design

 Dashboard
The dashboard provides insights into coffee shop sales, including sales trends, product performance, and other key business metrics.

  Analysis
The project analyzes:
Total sales
Sales trends over time
Product performance
Store/location performance
Customer purchasing patterns
Best-performing products
Sales by different categories
