# coffee-shop-sales-analysis-excel

## Project Overview
This project is an interactive Coffee Shop Sales Dashboard created using Microsoft Excel.

The purpose of this project is to analyze coffee shop sales data, identify trends and patterns, and present key business insights through an interactive and visually appealing dashboard.

## Tools & Skills Used
- Microsoft Excel
- Data Cleaning & Preparation
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Dashboard Design

## Analysis
The dashboard provides insights into:
- Total Sales
- Sales Trends Over Time
- Product Performance
- Store/Location Performance
- Best-Performing Products

## Dashboard
The dashboard provides insights into coffee shop sales, including sales trends, product performance, and other key business metrics.

- Clean and organize raw data
- Analyze data using Excel
- Build Pivot Tables and Pivot Charts
